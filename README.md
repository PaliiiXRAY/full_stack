# Full Stack Web Development Projects & Labs

A comprehensive repository containing modular frontend and full-stack web applications developed using modern **React**, **Vite**, and **JavaScript** for university coursework, assessments, and lab assignments.

---

## 🚀 Projects Overview

| # | Project Name | Directory | Description | Tech Stack |
|---|--------------|-----------|-------------|------------|
| 1 | **Online Learning Platform** | [`online-learning-platform`](./online-learning-platform) | Interactive e-learning portal featuring course catalogs, student dashboard, navbar navigation, and enrollment profile views. | React, Vite, CSS |
| 2 | **Personal Portfolio Dashboard** | [`personal-portfolio-dashboard`](./personal-portfolio-dashboard) | Multi-view personal portfolio and administration dashboard with client-side routing (Home, About, Contact, Profile, Settings). | React, React Router, Vite |
| 3 | **StudyHub Portal** | [`studyhub`](./studyhub) | Student collaboration workspace integrating task tracking, authentication context, and interactive dashboard views. | React, Context API, Vite |
| 4 | **Task Manager Assessment** | [`assess_proj`](./assess_proj) | Advanced task management application built with reducer-based state (`useReducer`), custom debounce/local-storage hooks, and real-time task analytics. | React, Vite, Custom Hooks |
| 5 | **Currency Converter** | [`currencyconverter`](./currencyconverter) | Real-time currency conversion calculator with responsive UI and dynamic rate calculations. | React, Vite, CSS |
| 6 | **Interactive Counter** | [`Counter`](./Counter) | Lightweight React counter demonstration showcasing state manipulation, conditional styling, and event handling. | React, Vite |

---

## 🛠️ Technology Stack

- **Frontend Library:** React 18 / 19
- **Build Tool:** Vite
- **Language:** JavaScript (ES6+)
- **Routing:** React Router DOM
- **State Management:** React Hooks (`useState`, `useReducer`, `useContext`, custom hooks)
- **Styling:** Modular CSS3, Flexbox, CSS Grid
- **Version Control:** Git & GitHub

## 💻 Getting Started

Each project is structured as an independent modular package. To run any project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PaliiiXRAY/full_stack.git
   cd full_stack
   ```

2. **Navigate to the desired project directory:**
   ```bash
   cd online-learning-platform
   # or: cd personal-portfolio-dashboard
   # or: cd assess_proj
   # or: cd studyhub
   # or: cd currencyconverter
   # or: cd Counter
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
